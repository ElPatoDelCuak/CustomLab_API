# Documentación API: Actualización Integral de Productos

Este endpoint permite actualizar todos los aspectos de un producto (datos base, tallas, características e imágenes) en una sola llamada atómica.

**URL**: `/api/productos/update/<id>/`  
**Método**: `PATCH`  
**Autenticación**: Token JWT (Bearer)  
**Permisos**: `IsAdminOrManager` (Admin o Manager)  
**Content-Type**: `multipart/form-data`

---

## Estructura del FormData

Debes enviar dos campos principales:

1.  **`data`** (String): Un JSON convertido a string con las instrucciones de actualización.
2.  **`new_images`** (Archivos): Las nuevas imágenes físicas que deseas subir.

### Estructura del campo `data` (JSON)

```json
{
    "producto": {
        "nombre_producto": "Camiseta Algodón Orgánico",
        "precio_venta": 24.99,
        "precio_original": 29.99,
        "precio_costo": 10.50,
        "stock": 170,
        "categoria": "Camisetas",
        "personalizable": true,
        "nuevo": false,
        "oferta": true
    },
    "tallas": {
        "tallas_to_delete": [105, 106],
        "tallas_to_upload": [
            { "talla": "XL", "stock": 50 }
        ],
        "tallas_to_modify": [
            { "id_talla": 107, "talla": "L", "stock": 100 }
        ]
    },
    "caracteristicas": {
        "caracteristicas_to_delete": [1, 3],
        "caracteristicas_to_upload": [5, 8]
    },
    "imagenes": {
        "imagenes_to_delete": [45, 48] 
    }
}
```

---

## Detalle de Operaciones

### Producto
Se actualizan solo los campos incluidos en el objeto `producto`.

### Tallas
- **`tallas_to_delete`**: Lista de IDs (`id_talla`) que se eliminarán permanentemente.
- **`tallas_to_upload`**: Objetos con `talla` y `stock` para crear nuevas variantes.
- **`tallas_to_modify`**: Objetos que DEBEN incluir el `id_talla` para actualizar su nombre o stock.

### Características
- **`caracteristicas_to_delete`**: Lista de IDs (`id_caracteristica`) cuya asociación con el producto será eliminada.
- **`caracteristicas_to_upload`**: Lista de IDs de características ya existentes que se asociarán al producto.

### Imágenes
- **`imagenes_to_delete`**: Lista de IDs (`id_imagen_producto`) que se borrarán (archivo y base de datos).
- **Nuevas imágenes**: Se envían como archivos binarios en el campo `new_images` del FormData.

---

## Respuestas

### Éxito (200 OK)
```json
{
    "success": true,
    "message": "Producto actualizado de forma integral"
}
```

### Error (400 Bad Request)
```json
{
    "success": false,
    "message": "Descripción detallada del error"
}
```
